🏠 House Price Prediction using Machine Learning

This project aims to predict house prices based on various features using a Linear Regression model.
It is designed to help real estate professionals and home buyers estimate property values based on historical data.

🔍 What the Project Does:
- Reads and processes a dataset containing features like area, bedrooms, bathrooms, parking, etc.
- Cleans the data and visualizes it using matplotlib.
- Trains a Linear Regression model using scikit-learn.
- Predicts house prices based on input features.
- Saves the trained model to a pickle (.pkl) file for deployment and reuse.

🌟 Key Features:
- Feature selection and data preprocessing
- Linear Regression modeling
- Data visualization
- Model serialization using pickle
- Simple and interpretable ML pipeline

🧠 Model Used:
- Linear Regression ✅ (Finalized Model)

After data analysis and exploration, the Linear Regression model was selected for its simplicity and good performance on numeric, continuous target prediction tasks like house pricing.

🚀 How to Run the Project:
1. Clone the Repository or download the files.
2. Install the dependencies:
   pip install -r requirements.txt
3. Run the notebook:
   Open `house-price-prediction.ipynb` in Jupyter Notebook or Jupyter Lab.
4. Train the model, view predictions, and explore visualizations.
5. Use the saved `model.pkl` to predict new house prices using a script or app.

📥 Sample Input:
Area: 3000 sq ft  
Bedrooms: 4  
Bathrooms: 3  
Parking: 2  

📤 Sample Output:
